# Коды ошибок

Код — латиница и `_`, **не меняется между версиями**: по нему ищут помощь и ведут журнал. Источник — `homensai_security.errors.ERRORS` (тексты RU/UK, уровень, «Что делать»). Всего кодов: 68.

## Как ловить

```python
from homensai_security import public_api as sec

try:
    sec.check_pin(entered)
except sec.SecurityError as exc:
    entry = sec.ERRORS[exc.code]             # level, ru, uk, what_to_do_ru, what_to_do_uk
    show(entry["level"], entry["ru"], entry["what_to_do_ru"])
```

`SecurityError` — подкласс `ValueError`. Поле одно: **`code`** (то же значение в `args[0]`); поля `details` нет — подробности (какой ключ, какой счёт) добавляет продукт в свой журнал, не в текст ошибки. Секреты в сообщении и коде не передаются. Уровни: `error` — действие не выполнено, нужно вмешательство; `warning` — ввод или состояние неверны, можно повторить; `info` — сведение.

Неверный пароль или PIN — не исключение: `verify_secret`/`verify_pin` возвращают `False`; счётчик ошибок и паузу ведёт продукт (`pin_failure`).

## Связь со справочником ошибок

- `spec/error-codes.json` — выписка кодов **копий, восстановления и цепочки копий** (66 кодов; их выдаёт код копий Rent, пока он не перенесён).
- Коды этого модуля (ключи, вход, WebAuthn, целостность, мастер) — `ERRORS` (68 кодов); пересекаются с выпиской 8: `drill_failed`, `drill_no_copy`, `kdf_params`, `recovery_checksum`, `recovery_format`, `recovery_wrong`, `shares_mismatch`, `shares_needed`.
- Единая открытая база HomenSAI/ERROR-DATABASE (решение 28.10-288) — **будущее подключение**: модуль заведёт в ней своё пространство кодов (`SEC-…`) и манифест; до подключения действуют коды этой таблицы без префикса, а при подключении текущие коды станут «старыми» (`transition.show_legacy_codes: true`). Коды не переиспользуются и не переименовываются.
