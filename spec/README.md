# Спецификация SECURITY-MODULE

Языконезависимое описание форматов, по которому модуль можно повторить на другом языке и открыть копию Rent без кода Rent.
Источник правды — код Rent (HomenSAI/Homensai-Rent, ревизия 284efde3, 13.11.2026), из которого модуль переносится пакетом
MOD; спецификация описывает то, что этот код реально пишет и читает. Почему выбраны именно эти методы — `docs/CRYPTO.md`.

Ключевые слова «ДОЛЖЕН», «НЕ ДОЛЖЕН», «МОЖЕТ» — в смысле RFC 2119.

## Версии форматов

| Формат | Метка версии | Где стоит метка |
|---|---|---|
| Манифест копии | `homensai-rent-archive/1` | `manifest.json` → `format` |
| Служебный бэкап | `homensai-rent-backup/1` | `manifest.json` → `format` |
| Конверт ключа | `HRKEY1 ` + `"v": 1` | префикс комментария ZIP и поле `v` |
| Закрытый ключ под паролем | `"v": 1`, `"kdf": "argon2id"` | объект `wrapped` |
| Запечатанный ключ восстановления | `"v": 1` | объект `sealed` |
| Манифест цепочки | `homensai-rent-chain/1` | `manifest.format` |
| Файл ключа подписи | `HRSIGN1` | первые байты файла |
| Журнал-цепочка | `homensai-journal/1` | константа кода |
| Поле базы | `v1gcm\|` (чтение также `v0stub\|`) | префикс BLOB |
| Слепой индекс | `bi2:` (платформенный `bi1:`) | префикс строки |
| Ключ восстановления / часть | `RK1-` / `RS1-` | префикс записи |
| Отпечатки | `HR1-` (ключ копий), `HS1-` (ключ подписи), `RK-` (ключ восстановления) | префикс записи |

Правило: любое изменение байтов формата — новая метка версии, новые вектора и запись здесь. Читатель ДОЛЖЕН отвергать
неизвестную версию (`corrupt`), а не угадывать.

## Общие соглашения

- Текст — UTF-8; JSON конверта ключа — только ASCII.
- **base64url** — алфавит RFC 4648 §5 **с дополнением `=`** (как `base64.urlsafe_b64encode`): 32 байта → 44 знака,
  16 → 24, 12 → 16, 48 → 64, 64 → 88. В PHC-записи Argon2id — обычный base64 без дополнения.
- **hex** — строчные знаки.
- **Канонический JSON** (манифест цепочки, журнал, конверт): ключи по алфавиту, разделители `,` и `:` без пробелов.
  В цепочке и журнале — `ensure_ascii=False` (UTF-8), в конверте — ASCII.
- Доменные разделители (строки в HKDF `info`, AAD, хэшах отпечатков) приведены байт в байт; `\x00` — нулевой байт.

## Тест-вектора

`vectors/*.json` создаёт `scripts/gen_vectors.py` кодом Rent (через `sys.path`); случайность на время генерации заменена
потоком SHA-256 от постоянной метки, поэтому повторный запуск даёт те же байты. Все пароли, ключи и данные вымышленные.

| Файл | Что проверяет |
|---|---|
| `argon2id.json` | Argon2id копий (пароль, PIN), PHC-записи входа, нормализация NFKC |
| `identity.json` | Закрытый ключ хозяйства под паролем и PIN (`wrapped`), отпечаток `HR1-` |
| `recovery.json` | Ключ восстановления `RK1-`, получатель X25519, `RK-` id, части Шамира `RS1-`, ключ из PRF |
| `envelope.json` | Комментарий `HRKEY1`: открытие паролем, ключом восстановления, двумя частями; ошибки |
| `archive.json` | Три файла копии целиком (ключ хозяйства, прежний `BACKUP_PASSWORD`, без пароля) и порча |
| `field-aead.json` | `v1gcm`, AAD, `bi2`, контрольное значение ключа, `v0stub` |
| `chain.json` | Ключ подписи, два манифеста с `prev`, подделка, журнал-цепочка и якорь |

Проверка: `python -m pytest tests/test_vectors.py` — независимая реализация по этим документам (без Rent), сверка с
кодом Rent и детерминизм генератора (если найден Rent: `HOMENSAI_RENT_PATH` или соседняя папка `../Homensai-Rent`),
схемы — если установлен `jsonschema`. Пересоздать: `python scripts/gen_vectors.py`.
